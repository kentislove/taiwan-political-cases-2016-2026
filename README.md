# 台灣三大政黨重大司法案件與制度治理檢視 (2016–2026)

本專題網頁收錄並橫向對比 2016 年至 2026 年間，台灣三大政黨（民主進步黨、中國國民黨、台灣民眾黨）所涉及之重大司法弊案、政商關係爭端與行政監管爭議。

## 專題特色
1. **法治客觀四分流**：嚴格劃分「判決定讞」、「法院審理中」、「檢方偵查中」與「查無不法簽結／不起訴確定」，恪守現代法治國家的無罪推定原則。
2. **多維度深度評析**：涵蓋「國家治理面向」、「行政官員面向」與「金流貪污面向」。
3. **金流與公帑損失性質區分**：精確釐清「實質公帑損失與呆帳」、「個人犯罪收賄所得」與「政策容積特許之市場商業開發估值」。
4. **互動式篩選器與視覺化圖表**：提供即時多條件案件檢索與統計圖表。

## 權威資料來源
- 司法院裁判書系統（最高法院確定判決、台灣高等法院、各地方合議庭判決）
- 最高檢察署與各地方檢察署起訴書、不起訴處分書、查無不法簽結公告
- 監察院糾正案、彈劾案與審計部中央及地方政府決算審核報告
- 中央通訊社、公共電視台等長期追蹤司法與政經議題之新聞紀錄
